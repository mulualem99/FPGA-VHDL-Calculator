# FPGA VHDL Calculator

## Overview
This project implements a simple calculator on the DE2-115 FPGA board using VHDL. The design performs 
arithmetic operations and displays results on seven-segment displays. The project includes 
HDL design, FPGA implementation, and simulation/testing using Quartus Prime Lite and ModelSim.

## Features
- FPGA-based calculator design
- VHDL implementation
- Arithmetic operation handling
- Seven-segment display output
- Simulation and testbench verification
- FPGA hardware implementation

## Tools Used
- Intel Quartus Prime Lite
- ModelSim
- VHDL
- DE2-115 FPGA Board
